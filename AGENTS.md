# Project Identity & Branding
- **Project Name:** **REXA** (`REXA-Player` on GitHub), powered by the **Anechoic Engine** (zero-echo real-time HRIR binaural DSP).
- **Naming Split (SEO vs. UI):**
  - Keep plain ASCII **`REXA`** in search-indexed locations (`README.md` H1, repo name, GitHub Release titles `REXA vX.Y.Z`, PyInstaller `--name "REXA"`, and archive filenames `REXA-Windows.zip` / `REXA-macOS-AppleSilicon.dmg`).
  - Use stylized **`ɦuk — Anechoic Engine`** inside the desktop app UI (`player_ui/main.py` window title).

# Project Architecture
- `hrtf_core/`: Cross-platform Rust DSP engine (`cdylib`). Build with `cargo build --release`. Keep audio callbacks zero-allocation and real-time safe.
- `player_ui/`: Python PySide6 UI + lazy `pyfar` SOFA loader + `pyqtgraph` spectrum visualizer. Calls `hrtf_core` via `dsp_bridge.py`.
- Never rewrite the UI or SOFA parser in Rust. Modify one module at a time.

# Key Implementation Conventions (Do Not Regress)
- **Fast Startup & Lazy Imports:** Keep heavy modules (`pyfar`, `scipy.signal.resample_poly`, `mutagen`, `soundfile`) lazy-loaded and defer `load_default_sofa()` / `load_session_state()` via `QTimer.singleShot(10, self._deferred_startup)` so the window opens immediately.
- **CPU Quality Modes (`low_end_mode`):**
  - Default is `CPU: Full Quality` (lossless `scipy.signal.resample_poly` HRIR resampling, 3x3s 8192-FFT `Tonal Match`, 60 FPS spectrum).
  - `CPU: Low-End` reduces `Tonal Match` analysis windows, uses fast linear HRIR resampling, and drops spectrum FPS to 10 FPS while keeping real-time Rust HRTF DSP active.
  - `_check_cpu_benchmark()` runs once on first boot using warmup + `np.median` across 16 Rust DSP blocks to avoid OS page-fault false alarms.
  - `LavaLampOverlay` stays dynamic but runs at 30 FPS idle / 15 FPS during playback, with cached Gaussian blob sprites composited into one 256x160 premultiplied frame and upscaled once. Never recompute per-pixel Gaussian fields or tile dither across the full window on every paint; that second animation loop made Classic/Glass slower than the already-static Glass 2.0.
- **Live Graph Performance Indicator:** `lbl_perf` (spectrum card) and `SettingsDialog.lbl_perf_status` / `lbl_perf_tips` show achieved vs selected Graph FPS from real `update_graph()` callbacks (`_track_graph_fps()`, ~`0.7s` window + light EMA), not from the timer interval. Full Quality defaults to a sustainable `60 FPS` (`GRAPH_FPS_DEFAULT_INDEX`, 16 ms `Qt.PreciseTimer`); `120 FPS` is opt-in and leaving Low-End CPU Mode restores `60`, not `120`. Below `90%` of target, tips suggest `60 FPS`, disabling Spectrum Gradient Fill, and Low-End CPU Mode. The visible theme label is `Glass 2.0`; keep the internal `macos27_glass` key unchanged.
- **Settings Gating & Light Text:** Grey out Glass 2.0-only controls **and their labels** (`Glass Stage`, `Native Tint`, `Panel Scrim`, `Native Style`, `Reset Stage Tuning`) in `Classic`, `Light`, and original `Glass`; keep Ambient Glow and Glass Border Rim active where they apply. On `macos27_glass` Light (and `light`), use solid `#3c3c43` secondary text and `#6e6e73` disabled text instead of translucent grey; never leave `opacity: 0.7x` inline styles on white panels. Custom-painted text (library delegate, stereo scope, peak scheme, and pyqtgraph axes/title/legend) must use `is_light_surface()` so Glass 2.0 Light is treated as a bright surface; dark surfaces keep bright text.
- **Windows Non-ASCII / Cyrillic Path Safety:** `netCDF4` / `h5py` inside `pyfar.io.read_sofa()` fails on non-ASCII Windows paths; `load_sofa()` copies non-ASCII paths to an ASCII temp directory before reading and never persists the bundled `default.sofa` path into `session.json`.
- **Spectrum Analyzer (`update_graph`):**
  - `Time Decay` uses calibrated millisecond time constants (`Instant=0ms`, `Fast=20ms`, `Medium=42ms`, `Slow=70ms`).
  - `Input` and `Processed Output` use a sliding sub-block cursor (`h_audio`) from atomic `viz_state` for true 10/30/60/120 FPS motion.
  - `HRIR Only (Raw)` is computed directly in the frequency domain from `P_in * (|H_LL_raw|^2 + |H_RL_raw|^2)` (and equals `P_in_db` when bypassed) so it stays phase-locked with zero ring-buffer seam jumps.

# Git & Release Workflow
- **NEVER push to GitHub unless the user explicitly says it can be pushed** (e.g. “you can push now”, “push it”, “it can be pushed”). Local commits are allowed; `git push`, pushing tags, and opening PRs require explicit approval every time. If unsure, do not push.
- Pushing tags matching `v*` (currently `v0.5.3`) triggers `.github/workflows/build-release.yml` to build Windows (`REXA-Windows.zip`) and macOS Apple Silicon (`REXA-macOS-AppleSilicon.dmg`) releases titled `REXA vX.Y.Z`.
- When sharing terminal patches for `player_ui/main.py`, keep scripts compact (under ~60 lines) or split into two parts so they fit cleanly in terminal paste buffers.
- See `docs/LIQUID_GLASS_HANDOFF.md` for the current liquid-glass / `Glass 2.0` work state and exact local-only commit commands.

# Recent Additions & Architecture Updates (v0.3.8+)
- **Platform Focus:**
  - Active release targets are **Windows (`REXA-Windows.zip`)** and **macOS Apple Silicon (`REXA-macOS-AppleSilicon.dmg`)**. Android (`android_app/` + `android_core/`) is paused/experimental until desktop feature parity is complete.
- **Driver-Free macOS System Audio (`macos_tap/huq_tap.m` -> `libhuq_tap.dylib`):**
  - Never install experimental HAL plugins in `/Library/Audio/Plug-Ins/HAL/`; use the pure user-space CoreAudio Process Tap (`CATapDescription` with `CATapMuted` and `stereoGlobalTapButExcludeProcesses` excluding `REXA`'s own PID).
  - Controlled via the single **`Go Live`** button (`toggle_go_live`): locks `engine.fs` to the tap's native sample rate, defaults volume to `80%` (restoring `44%` local volume on exit), disables `Prev/Next/Seek/Export`, and runs `_update_live_tonal_match` every `1.5s` with a `0.25 dB` stability deadband.
  - `.github/workflows/build-release.yml` compiles `libhuq_tap.dylib`, bundles it via PyInstaller `--add-binary`, and injects `NSAudioCaptureUsageDescription` into `Info.plist`.
- **Limiter & Bit-Perfect Safeguards (`player_ui/main.py`):**
  - Rust receives `hard_clip=False` so Python sees true unclipped post-HRTF peaks; when `Hard Clip (Exact)` (`not float_mode`) is active, `auto_trim_gain` enforces a `-0.5 dBFS` (`0.94406`) ceiling (`1.015`/block release, instant reset when lowering volume) and displays live attenuation as `Peak: -X.X dB (LIM -Y.Y dB)`.
  - `Bit-Perfect` uses `RightClickPushButton`: **Left-Click** runs an exact `2.0s` (`80 x 25ms`) RME-style volume ramp to `100%` before locking `bit_perfect=True`; **Right-Click** jumps instantly to `100%`. Temporary `100%` Bit-Perfect / `80%` Live volumes are never persisted to `session.json`.

## UI & Styling Architecture Rules (`player_ui/`)

1. **Never Toggle `WA_TranslucentBackground` at Runtime:**
   * On macOS PySide6, flipping `Qt.WA_TranslucentBackground` after `window.show()` recreates the native backing store and causes black/gray paint glitches.
   * Keep `WA_TranslucentBackground` enabled once in `__init__` (guarded by `windows_transparency_enabled()` on Windows). `Classic` and `Light` paint `100%` opaque gradients (`alpha=255`) over `centralWidget` and `settingsRoot`, while `Glass` paints translucent tints over the native blur view.
2. **Avoid Mismatched `border-top`/`border-bottom` Colors with `border-radius`:**
   * Always use uniform `border: 1px solid ...` rules in `build_liquid_qss()` so Qt does not draw 45-degree corner miter seams.
3. **Valid QSS Sub-Control Pseudo-States:**
   * Always place `:disabled` **after** sub-controls (`QSlider::sub-page:horizontal:disabled`, never `QSlider:disabled::sub-page:horizontal`), otherwise Qt's CSS parser drops the slider groove height rule.
4. **Stock Theme Defaults & Persistence (`session.json`):**
   * `theme_glow`: `{"classic": 0.20, "light": 0.30, "liquid_glass": 1.00}`
   * `glass_material`: `automatic` | `glass_clarity`: `45` (legacy/automatic fallback) | `glass_rim`: `10` (`DEFAULT_GLASS_RIM`)
   * `Panel Scrim` slider runs `50–100` only: `50%` is a fully transparent scrim and `100%` is full alpha. The old lower half was cut off so the whole track is useful; `_alpha_to_scrim_slider()` / `_scrim_slider_to_alpha()` map between the slider and stored alpha.
   * Keep `SettingsDialog` synced with `MainWindow` via `sync_from_main()` and `_on_ambient_color_changed()`.
5. **Layout & Text Overflow Protection:**
   * Use `MarqueeLabel` (with `QSizePolicy.Ignored`) for dynamic track metadata so long titles never compress `lbl_cover` or push right-side controls.
   * Keep `combo_group` at `min-width >= 116px` (`view().setMinimumWidth(126)`) and `btn_sort_dir` at `50px` with `padding: 6px 4px;` so `"Custom"` and `"A-Z"`/`"Z-A"` never elide or clip.
   * The main player content lives in `QScrollArea#mainScroll`; opening DSP controls (or Stereo scope) grows the scrollable content instead of squishing the cover/transport/spectrum. Auto-scroll to the bottom when those controls are toggled on; users scroll up for the cover and other controls. `_sync_main_content_height()` caps the content at the viewport height normally and adds only the DSP panel height when open, so default proportions match the pre-scroll layout and no scrollbar appears until needed. The scroll viewport and `QWidget#mainContent` must be created transparent (`WA_TranslucentBackground`, `WA_NoSystemBackground`, `autoFillBackground=False`) or the plain content widget paints an opaque palette fill and hides the native glass. The default window is `1100x880`; cover/top controls keep their stock `820px` proportions (`h = min(self.height(), 820)`) and the library starts at `760px`, top-aligned with the right panel. Once the viewport grows past `880`, `_sync_main_content_height()` grows the library by the same extra height so maximized/fullscreen windows do not leave a short library; the cover/top controls still keep their stock proportions. Both this scroll area and `SettingsDialog.settings_scroll` must resync per-card native glass on scrollbar changes; `SettingsDialog.showEvent()` must drop stale window/panel glass and reapply it on every open. DSP controls always start closed and `dsp_panel_open` must never be persisted/restored.
 6. **Native macOS Glass Style:** `pyqt_liquidglass` defaults `NSGlassEffectView` to `Regular`. Always call `configure_macos_glass()` after `apply_glass_to_window()` and whenever `Glass Stage` changes. `macos27_glass` uses `DarkAqua` by default + a 14pt corner radius + transparent root — `VibrantDark` reads too bright/blue next to native Settings; original `Glass` keeps `Regular (0)` + `VibrantDark`. **Never lower `NSGlassEffectView.alphaValue`** — AppKit then hides the material and the window looks flat; keep it at `1.0`. The UI exposes only `Glass Stage` (`Dark` / `Light`); the old `Glass Material` selector was removed because it acted as a confusing stage modifier. Stage maps to DarkAqua/dark tint/scrim or Aqua/white tint/scrim, using public Clear style with a fixed full backdrop downsample (`0.50`) in normal mode and `~1/3` (`0.33`) in Low-End CPU mode, via guarded private KVC best-effort, reapplied after layer rebuild and on window move/resize because AppKit resets it; public Regular is an advanced opt-in override. Advanced sliders persist clamped **per-stage** overrides (`tint_alpha`, `card_alpha`/`list_alpha`, public Clear/Regular style) under `glass_overrides`; the old `Backdrop Downsample` slider was removed and is not manually tunable. Label these as best-effort experimental values, not a public blur API. macOS has no public blur-radius API or readable exact native mode; do not claim otherwise. Keep the ambient/lava overlay static in `macos27_glass` (peak alpha `0.09 * glow`, no dither tile) and original `Glass` (peak `0.22 * glow`) — the user found the old `0.015` ceiling too weak. Keep the Dark stage dark — references are dark macOS panels over a picture background; `Light` is the explicit white-panel exception. The Dark preset uses native tint alpha `0.52` with near-black RGB and QSS scrim `176` (list `168`) so panels read darker and text stays readable while native blur still shows through; `configure_macos_panel_glass()` puts an `NSGlassEffectView` behind each `QFrame#glassCard` (panel tint `0.16` Dark / `0.06` Light) because QSS alone cannot blur the wallpaper behind a panel; always insert these views into `root_view.superview()` below `root_view` (matching `pyqt_liquidglass` sibling injection), never into `contentView()` with an invalid sibling, or AppKit stacks them above all Qt controls; `GLASS_STAGE_TINT_MAX` caps Dark `Native Tint` at `52` (Light keeps `0–100`) and old overrides over the cap are clamped on load/save; these are best-effort visual values, not a blur-radius control. In `macos27_glass` Dark, ease the upper half of `Glass Border Rim` (`r_highlight = min(r, 0.5) + 0.30 * max(0, r - 0.5)`) so white rim/button highlights do not blow out past the middle; Light keeps its original curve. Accent stays muted; neutral at Ambient Glow 0.
 7. **Cover Lens Pill:** The WebGPU-style `GlassLensOverlay` is only for the original `Glass` theme and only when a real cover pixmap exists. Never render its accent-gradient fallback, and keep it hidden in `macos27_glass` to match native macOS Settings.
 8. **System Glass Sync:** Double-clicking `Glass Stage:` in `SettingsDialog` calls `read_system_glass_preferences()` and maps public OS appearance signals to a best-effort `Dark` / `Light` stage. macOS: effective appearance, `AppleInterfaceStyleSwitchesAutomatically`, `NSWorkspace.accessibilityDisplayShouldReduceTransparency()`, and main-wallpaper luminance; Windows: `AppsUseLightTheme` + `EnableTransparency`. Do **not** claim exact macOS `Default/Dark/Clear/Tinted` detection — those values are not public. Android is paused/experimental and has no system sync yet.
  9. **Theme-Switch Cleanup:** After `glass.remove_glass_effect()`, always call `clear_macos_glass_state()` so stale `_glass_view`, backdrop-scale state, and the move/resize event filter cannot accumulate. `remove_macos_panel_glass()` must remove its event filter from both the window and every card, invalidate queued syncs with a generation counter, and `schedule_macos_panel_glass_sync()` must coalesce scroll/show/resize syncs. `reset_macos_window_opaque()` must read `className()` through PyObjC (not ctypes `c_char_p`) — the old raw-NSString read was the repeated-theme-switch segfault. Native glass view counts must stay constant across repeated theme changes.

## v0.5.3 Architecture & Build Notes
- **Settings Native-Glass Lifecycle:** `SettingsDialog.showEvent()` drops stale window/panel glass before reapplying, and `hideEvent()` calls `_clear_native_glass()` so dialog-owned `NSGlassEffectView`s cannot survive `close()` and darken the main window on the next activation.
- **Seamless Geometry Restore:** `WindowDragFilter` saves Qt content geometry (not AppKit frame geometry), and `_animate_to()` / `showNormal()` settle exact `setGeometry()` synchronously with bounded `processEvents()` when shrinking, so fixed-height library cards cannot leave a stretched graph.
- **Graph FPS Contract:** `lbl_perf` and `SettingsDialog` report achieved vs selected FPS from real `update_graph()` callbacks; Full Quality defaults to 60 FPS, 120 FPS is opt-in, and leaving Low-End CPU Mode restores 60.
- **Ambient & Cover Performance:** `LavaLampOverlay` composites cached Gaussian sprites at 30 FPS idle / 15 FPS playback; lazy cover decoding uses four workers, stamp/content caches, direct thumbnail scaling, and cancels offscreen work.
- **Immediate Ambient Switch:** Track changes apply the sampled cover color to QSS background, accent, and lava in one pass. The old 600 ms `QVariantAnimation` was removed because it kept the previous hue visible in the wash while the accent and lava had already switched. Manual theme/opacity/Settings changes still re-derive the accent from the target color.
- **Version Source:** `player_ui/main.py` `APP_VERSION` is the single in-app version string; the release workflow derives release names/assets from the pushed `v*` tag, so a local `v0.5.3` tag is enough to publish `REXA v0.5.3` once explicitly approved.

## v0.5.2 Architecture & Build Notes
- **Pre-baked HRTF Profile (`player_ui/default_sofa.npz`):** Bundled into PyInstaller releases so first startup skips importing `pyfar`/`sofar`/`netCDF4`/`h5py` (preventing Windows HDF5 thread deadlocks and enabling <0.5s cold starts).
- **Last.fm App Keys (`player_ui/lfm_keys.py`):** Gitignored locally; injected at CI build time from `LFM_API_KEY` and `LFM_API_SECRET` GitHub Actions repository secrets.
- **In-App Updater (`UpdateCheckThread` / `UpdateInstallThread`):** Queries `://github.com`, strips `com.apple.quarantine` on macOS `.app` updates, and uses a detached `.bat` swapper on Windows.
- **Library Delegates & Dialogs:** `MarqueeDelegate` renders non-selectable `56 px` album cover headers (`_is_header`) and async per-track cover strips via `ThreadPoolExecutor`; `SettingsDialog` and `_show_track_properties` are non-modal so `Cmd+Q` / window close never blocks.
